# WDP301-192 - Task supervision UI

## Approved scope

The user approved keeping the existing read-only supervision behavior, filters,
queues, metrics, workload table, and detail screen. The list uses the prototype
table presentation and additional content uses shared Panels. The prototype
offers create and reassign actions and has no matching detail screen; those
actions are excluded. Existing API calls, query behavior, routing, permissions,
keyboard tab handling, and accessible names remain.

The pages reuse PageContainer, PageHeader, Panel, DataTable, atomic controls,
Alert, and EmptyState. The shared DataTable gained `showPagination={false}` to
display all client-filtered workload rows without a second, misleading pager;
the default and server-page behavior remain unchanged. The component catalog was
updated. No dependency or backend change was required.

## Regression evidence

The original task supervision suite passed 35 tests. A new test covers blocked
task details and recovery history without writes; all 36 passed on the original
page and the migrated page. The no-pagination DataTable test failed before its
implementation and passed afterward. Existing behavior assertions were not
changed. The focused component and feature suites passed 38 tests in total.
